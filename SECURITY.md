# Security policy

## Reporting a vulnerability

Do not report security issues in public bug reports. Use GitHub's private
vulnerability reporting on the
[`andresako/pi-hole-extended`](https://github.com/andresako/pi-hole-extended/security/advisories/new)
repository (Security tab → Report a vulnerability).

Please do not include Pi-hole application passwords, session IDs, DNS query
logs, or private network addresses in public reports.
