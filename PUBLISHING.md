## Request default HACS inclusion

An editable pull request is open at
[`hacs/default#12355`](https://github.com/hacs/default/pull/12355). HACS reviews
default inclusion separately; it is not immediate. The software can be
installed as a custom repository while that request is pending.

This is inclusion in the HACS default catalog. It does not mean the integration
has been accepted into Home Assistant Core.
